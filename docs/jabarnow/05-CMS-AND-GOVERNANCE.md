# CMS & Governance — Keputusan Terkunci

## CMS
- Tema light; navigasi/sidebar CMS charcoal.
- Delapan role: Super Admin, Administrator, Pemimpin Redaksi, Editor, Reporter, Contributor, Ads Manager, SEO Manager.
- Workflow editorial preset Simple / Advanced, dipilih Admin sesuai izin; bukan workflow builder bebas.
- Notifikasi **dashboard saja**.
- Editor artikel block-based: paragraf, heading, gambar, kutipan, embed, tabel, link, daftar.
- Analytics advanced: views, sumber trafik, artikel populer, performa penulis (jika data tersedia).
- Autentikasi email/password standar, tetap wajib proteksi keamanan dasar, audit log dan session management.
- CMS full responsive untuk menulis dan mengelola artikel dari mobile sesuai izin.

## Ads Manager
- Format: banner gambar, HTML, script jaringan iklan yang disetujui.
- Manual placement + jadwal kampanye; tidak mengasumsikan rotasi atau targeting otomatis.
- Preview script pihak ketiga perlu isolasi dan kontrol akses.

## SEO Manager
- Advanced internal SEO: metadata, canonical, schema NewsArticle, sitemap, redirect, audit SEO.
- Siap integrasi GSC/Analytics; integrasi langsung bukan kewajiban saat V1 diluncurkan.
- Jangan menampilkan angka indexed URLs sebagai data aktual tanpa sumber GSC.

## Pengelolaan logo
- Logo utama dan favicon diunggah manual oleh Super Admin.
- Tidak ada regenerasi atau tracing ulang logo dari mockup.
- Pratinjau header putih, mobile, footer charcoal; pertahankan rasio asli.

## Yang belum difinalkan
- Detail Artikel desktop/mobile, kategori, wilayah, author, search, halaman legal, seluruh layar CMS.
- Ukuran akhir beberapa komponen masih memerlukan pengukuran dan visual QA.
