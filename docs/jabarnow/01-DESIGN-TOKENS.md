# JabarNow! — Design Tokens V2.1

## Warna terkunci
| Token | Nilai | Penggunaan |
|---|---|---|
| brand.primary | `#F4511E` | CTA, aksen aktif, angka Most Read |
| editorial.breaking | `#C62828` | Breaking news, peringatan editorial |
| text.primary / surface.charcoal | `#17191D` | Teks, nav, footer |
| surface.base | `#FFFFFF` | Kanvas utama |
| surface.muted | `#F7F8FA` | Section alternatif |
| border.default | `#E5E7EB` | Garis pembatas |

Gunakan orange sebagai aksen, bukan untuk semua headline. Pastikan kontras teks sesuai WCAG; untuk teks kecil di atas orange, verifikasi rasio kontras dan gunakan warna teks yang lolos pengujian.

## Tipografi
- Judul: Plus Jakarta Sans, 700–800.
- Isi, label, metadata dan UI CMS: Inter, 400–600.
- Hero: desktop 38px; mobile 26px.
- Heading section: desktop 24px; mobile 21px.
- Card title: desktop 18px; mobile 16px.
- Isi artikel (untuk desain Detail Artikel nanti): desktop 18px; mobile 17px.
- Metadata: 12px, namun ukuran minimum aksesibel harus diuji.

## Grid dan ruang
- Artboard desain desktop 1440px; container maksimal 1200px.
- Grid desktop 12 kolom; area konten/sidebar kira-kira 8:4.
- Mobile target 390px, validasi 360px dan 430px; margin kiri/kanan 16px.
- Tablet validasi 768px dan 1024px.
- Gap desktop 24px; mobile 12–16px.
- Jarak antar-section desktop 48px; mobile 28px.
- Radius card 10px.

## Ukuran baseline untuk diuji saat implementasi
- Topbar desktop 32px.
- Main header desktop sekitar 104px, boleh disesuaikan agar logo proporsional.
- Desktop nav 48px, breaking ticker sekitar 42px.
- Mobile header sekitar 56px.
- Mobile fixed bottom nav sekitar 64px ditambah safe-area inset.

Nilai ukuran ini adalah baseline desain yang telah dibahas, bukan hasil pengukuran dari gambar mockup. Deviasi terkontrol memerlukan review visual sebelum diterima.
