# Checklist Validasi Desain JabarNow!

## Homepage desktop
- [ ] Logo yang digunakan adalah file resmi dari upload CMS, bukan gambar hasil rekonstruksi.
- [ ] Header putih; navbar charcoal compact sticky.
- [ ] Hero 1+2 tanpa carousel dan dot.
- [ ] Mixed news layout dan Most Read hanya 24 Jam / 7 Hari.
- [ ] Tidak ada direktori 27 wilayah pada homepage.
- [ ] Footer gelap empat kelompok lengkap.
- [ ] Iklan bukan materi sponsor fiktif yang dianggap nyata.

## Homepage mobile
- [ ] Hero statis + 2 pendamping.
- [ ] Iklan pertama tepat setelah seluruh hero.
- [ ] Bottom nav fixed terlihat, tidak menutupi konten/footer.
- [ ] Header/hamburger/search berfungsi sesuai spesifikasi.
- [ ] Uji 360/390/430px dan orientasi berbeda.

## Universal
- [ ] Token warna/font/spacing konsisten.
- [ ] State loading, empty, error, gambar gagal tersedia.
- [ ] Keyboard, focus, kontras, alt text diuji.
- [ ] Gambar cover tidak merusak subjek penting; focal point dapat diatur.
- [ ] Semua perubahan locked disetujui Super Admin dan dicatat.

**Catatan:** checklist ini untuk QA saat desain/implementasi; kotak belum dicentang karena pengujian nyata belum dilakukan.
